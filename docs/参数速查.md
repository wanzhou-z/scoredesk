# 实时榜单 URL 参数速查

榜单地址形如：

```text
http://127.0.0.1:8791/board?overlay=1&rows=12&scroll=1
```

多个参数用 `&` 连接。下表的「默认」是该参数**不写时**的行为；其中一部分参数会先读 `config.json` 的 `view` 字段，再退回代码默认值。

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `overlay` | `0` | `1` = OBS 叠加模式：透明背景、隐藏标题栏/控制条/页脚等所有控件。 |
| `top` | `0` | 只显示前 N 名；`0` = 不截断。 |
| `rows` | `13` | 一屏显示的行数；`0` = 显示全榜（行高自动压缩，配合 `scroll=0` 最合适）。 |
| `scroll` | `1` | `1` = 自动滚动；`0` = 静止。 |
| `scroll_speed` | `24` | 滚动速度（像素/秒，1–200）。 |
| `scroll_pause` | `2` | 滚到端点后的停顿秒数（0.2–30）。 |
| `anim` | `1` | `0` = 关闭所有动效（画面静止）；控制条的「自动滚动」勾选也会如实显示未生效。 |
| `scale` | `1` | 整体缩放（0.4–2），用于适配不同分辨率的投屏。 |
| `font` | `yahei` | 页面字体名；默认用内置/本地雅黑，填其它字体名会覆盖 `font-family`。 |
| `title` | 空 | 页面标题。取值链：`?title=` → 配置里的 `title` → PTA 比赛名 → `ScoreDeck · 实时榜单`。 |
| `freeze` | 配置值 | `audience` = 封榜视角（观众看到封榜快照）；`operator` = 操作员视角（可看真实成绩）。不写时取 `config.json` 的 `freeze_mode`。 |
| `auto` | `1` | 控制条上的「自动滚动」开关初值；`0` = 打开页面时不自动滚。 |
| `ctl` | 页面 `1` / 叠加 `0` | 控制条是否显示；`overlay=1` 时默认不显示。 |
| `resume` | `10` | 手动拖拽/滚轮后，多少秒自动恢复滚动；`0` = 永不自动恢复。 |
| `ctlhide` | `4` | 静止多少秒后控制条淡出；`0` = 一直显示。 |
| `follow` | `0` | `1` = 排名上升时自动跟随（滚动到变化行）；配置里有 `view.follow` 时以配置为准。 |
| `follow_pause` | `2.5` | 每次跟随滚动前的停顿秒数（0.2–60）。 |
| `follow_max` | `6` | 跟随频率上限（次/分钟，0–600），防止连续换位时刷屏。 |
| `thaw` | `0` | `1` = 解榜，揭示真实成绩（等价 `freeze=operator`）；观众页不要带这个参数。 |
| `dense` | 自动 | **不是 URL 参数**：窗口/行高变小时自动挂 `body.dense`（行高 < 44px）。保留在表里是为了说明它的来源。 |
| `compact` | 自动 | **不是 URL 参数**：内容高度 < 900px 时自动挂 `body.compact`。 |
| `classic` | `0` | `1` = 旧视觉（改动前的样式，逐像素对比/排障用），同时不挂新皮肤与主题类。 |
| `theme` | `light` | 新皮肤主题：`light` / `dark`。`classic=1` 时无效。 |
| `cells` | `ref` | 题格样式：`ref` = 填充 + 次数 + 时间；`ours` = 旧的「数字上色」（`+N / −N / · / ?`）。 |
| `star` | 空 | `problem` = 一血星标跟题目色；不写 = 金色 ★。 |
| `postink` | 空 | `white` = 琥珀格用白字（照参照榜原值）；默认深色字。 |
| `timebar` | `1` | `1` = 显示滚榜时间轴（时间码 + 滑块 + 播放键）；`0` = 隐藏。 |
| `sweep` | `180` | 定时扫榜的间隔秒数（默认 3 分钟一轮）；`0` = 关闭扫榜，退回旧的乒乓滚动（需 `scroll=1`）。 |
| `sweep_speed` | `16` | 扫榜速度（像素/秒，最小 6）。 |
| `rankmove` | `900` | 名次变化行的滑动动画时长（毫秒）；`0` = 直接跳位。 |
| `acanim` | `1` | `0` = 关闭 AC 时的闪烁/滑入动效。 |

## 其它可用参数

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `palette` | 空 | `roll` / `rank`：切换题格配色的来源（默认按滚榜页实测值）。 |
| `follow_team` | 空 | 指定一个队名/队 ID，页面跟随该队所在位置。 |
| `refresh` | 空 | `full` = 打开页面时请求一次全量刷新（不限页数 + 刷新队伍名录）。 |
| `ctlhint` | `3` | 加载后控制条先显示多少秒做提示；`0` = 不提示。 |

## 常用组合

| 场景 | 参数 |
| --- | --- |
| OBS 透明叠加、一屏 12 行自动扫榜 | `?overlay=1&rows=12&scroll=1` |
| 大屏静态全榜（队伍少） | `?rows=0&scroll=0&anim=0` |
| 人工翻看、控制条常显 | `?auto=0&ctl=1&ctlhide=0&rows=0` |
| 封榜期间的观众视角 | `?freeze=audience` |
| 赛后自己核对最终成绩 | `?thaw=1` |
| 旧版视觉排障 | `?classic=1` |
## 外榜（往期存档）页额外参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `poll` | `5` | 自动刷新间隔（秒，2~60）。存档被重新上传/解榜后，页面会自己更新（名次按实时榜那套动效滑动），不用按 F5。`poll=0` 关掉自动刷新，只拉一次 |
| `fit` | 自动 | 外榜页按窗口高度等比缩放，把整张榜铺满屏幕（1920x1080 为基准，只放大不缩小）。`fit=0` 关掉；`fit=1.3` 手动指定倍数 |

其余参数（`rows` / `anim` / `scroll` / `overlay` …）与实时榜完全一致，直接加在外榜单场网址后面即可。
