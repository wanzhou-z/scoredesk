# VJudge 使用说明

ScoreDeck 从 **v0.2.0** 起支持 VJudge。抓取层不同，但实时榜单、滚榜、外榜全部沿用同一套逻辑（两个平台产出同一份 `contest.json`）。

## 1. 需要填什么

「实时榜单 → 1 数据源」最上面先把**平台**切到 **VJudge**，然后：

| 项 | 怎么填 |
| --- | --- |
| 比赛 ID | 填 `862258` 这种数字；也可以直接粘整条网址 `https://vjudge.net/contest/862258#rank` |
| Cookie | **公开赛留空**；私有 / 有密码的比赛需要带登录后的 Cookie（`--cookie-file`），这一项还没在真实密码赛上验证过 |
| 封榜时长（分钟） | VJudge 接口不返回封榜设置，所以**按你填的算**（0 = 不封榜）。填 60 就是最后 60 分钟封榜 |
| 多久取一次 | VJudge 默认 10 秒一轮 |

点「开始检查」→「拉取数据」，日志里出现 `抓取成功（VJudge）… 题 / 队 / 提交` 就到手了，接着去「4 服务」启动、打开榜单页。

## 2. 队伍备注（把 handle 变成真实姓名）

VJudge 只给账号 handle（如 `mu_yu`），没有学号和真实姓名。用「实时榜单 → 2 队伍备注」补：

1. 双击某行的「备注姓名」→ 输入真实姓名 → 回车保存；
2. 「校徽」一格三种填法：
   - **留空** = 按备注姓名去 `校徽\` 目录找同名图片（`张三.png`）；
   - **填文件名**（`张三.png` 或 `张三`）= 用 `校徽\` 目录里这张；
   - 点「选择校徽图片…」（先点住那一行的校徽格）= 选一张图，程序自动复制成 `校徽\<备注姓名>.png` 并填好；
3. 备注名要生效：点一次「1 数据源 → 重新拉取数据」，或者等下一轮轮询。

**校徽显示优先级**（实时榜和滚榜一致）：

```
备注里指定的校徽  →  VJudge 头像  →  默认校徽（校徽\logo.png）
```

VJudge 头像地址是 `cn.cravatar.com`，国内经常连不上；程序会自动换 `cravatar.com` / `secure.gravatar.com` 再试，都失败才回落到默认校徽。

## 3. 已知限制（不是 bug，是接口限制）

| 项 | 现状 |
| --- | --- |
| 封榜设置 | 接口不提供，必须自己填「封榜时长」 |
| 题目标题 | 接口没有，题目名用字母 A/B/…/AA… |
| 编译错误（CE） | rank 接口只有「通过 / 未通过」，CE 归到未通过，**不计罚时**（和 PTA 版不同） |
| 密码赛 | 支持带 Cookie，但**未在真实密码赛上验证** |
| 罚时口径 | 与 VJudge 网页一致：每题「秒数/60」相加后整体向下取整（已验证 6 支队逐队一致） |

## 4. 常见问题

- **一直显示「未加载」**：多数是浏览器缓存了旧的 404 图，按 `Ctrl + F5`；换过校徽图之后要「4 服务 → 停止 → 启动」才会重建校徽索引。
- **某队没有头像**：公开接口里该选手没有头像，或三个头像域名都连不上；把头像图放进 `校徽\<备注姓名>.png` 即可。
- **数字和网页差几分钟**：先确认「封榜时长」没填错；口径不同主要出现在封榜后。
