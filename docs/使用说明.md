# ScoreDeck 使用说明

本说明对应源码仓库的运行方式。想直接打包成 exe，见 `scripts/build-windows.bat`。

## 一、这是什么

一个窗口，两种模式：

- **实时榜单（比赛中）**：从 PTA 实时拉取各队解题情况，在本机生成一个网页榜单。可以给 OBS 当「浏览器」来源，也可以直接用浏览器打开投屏。
- **赛后滚榜（比赛后）**：比赛结束后，按记录生成比赛包，用 ICPC Resolver 播滚榜动画。

两种模式共用同一份设置，用哪个模式就切到哪个模式，不用来回改配置。除此之外还有独立的**外榜**（Outrank）服务，用于赛后长期展示往期榜单，见 `docs/外榜部署.md`。

## 二、运行环境

程序界面本身不挑环境，装好 Python 就能打开。但两种模式各自还需要一样东西，而且仓库里**没有**自带：

- **实时榜单**：需要本机已安装 Python 3.9 或更高版本。取数用的后台进程需要一个真正的 Python 解释器来运行（即使你用 exe，也建议装好 Python）。
- **赛后滚榜**：需要本机已安装 Java 17 或更高版本，以及 ICPC Resolver 2.6 发行包（第三方，需自行下载）。

确认方式：打开命令行（Win+R 输入 `cmd` 回车），输入

```bat
python --version
java -version
```

应分别看到 `Python 3.x.x` 和 `version "17"` 或更高。程序里的「数据源 → 环境预检」也能看到 Java / Resolver / 字体 / Cookie 的检测结果（环境预检不检测 Python，请按命令行确认）。

如果 Python 装在非常规位置，可以设环境变量 `PTA_PYTHON` 指向那个 `python.exe` 的完整路径，程序会优先使用它。

### ICPC Resolver 与字体

这两样都不随仓库分发，需要放到程序目录的固定位置：

```text
tools/
├── resolver/
│   └── app/
│       └── lib/
│           └── resolver.jar      ← ICPC Resolver 2.6 解压后放这里
└── fonts/
    └── MicrosoftYaHei.ttc        ← 任意你有权使用的中文字体（可选）
```

- Resolver 由 ICPC 工具组发布，遵循其自身许可；
- 字体只影响滚榜时中文是否显示为方框，也可以在「外观」页手动选择一个中文字体文件；
- 缺 Resolver 时实时榜单不受影响，只有点「启动滚榜」会提示缺失。

## 三、怎么开始

### 从源码运行

1. 安装依赖：

   ```bat
   python -m pip install -r requirements.txt
   ```

2. 启动图形界面：

   ```bat
   python app\pta_assistant_gui.py
   ```

3. 如果只想跑实时榜单服务、不开 GUI，用 `scripts\run-liveboard.bat`；
   只跑外榜用 `scripts\run-outrank.bat`。

### 使用打包版

```bat
scripts\build-windows.bat
```

产物在 `dist\ScoreDeck\`。把**整个文件夹**复制到普通目录（例如桌面或数据盘）再运行，不要只拷 exe，也不要放在 `Program Files` 这类受限目录。

## 四、实时榜单：开始前必须做两件事

打开「1 数据源」页，填好下面两项。

### (1) 题目集 ID

PTA 比赛网址里 `/problem-sets/` 后面那串数字。例如：

```text
https://pintia.cn/problem-sets/<题目集 ID>/problems/123
```

### (2) 有效的 PTA Cookie

必须同时带 `JSESSIONID` 和 `PTASession`，只带 `PTASession` 会返回 401。

取法一（推荐）：复制 cURL

1. 浏览器登录 `pintia.cn`，按 F12 打开开发者工具；
2. 切到「网络 / Network」，刷新比赛页面；
3. 在请求列表里右键任意一条 `pintia.cn/api/...` 请求；
4. 「复制 / Copy」→「以 cURL (bash) 格式复制 / Copy as cURL (bash)」；
5. 回到程序「1 数据源」页，点「粘贴 cURL 自动生成」，粘贴进去。

取法二：手动拼一行

开发者工具 →「应用程序 / Application」→ Cookie → 选 `https://pintia.cn` → 复制两个值，拼成：

```text
JSESSIONID=xxxxxxxx; PTASession=yyyyyyyy
```

> 本版本取数只有「直连接口 + Cookie」这一条路，不会借用浏览器，所以浏览器里没有下载记录是正常的。

## 五、页面怎么用（实时榜单）

1. 「1 数据源」：填题目集 ID、Cookie，点「环境预检」确认没有红叉；
2. 「3 服务」：点「启动」，把后台取数和榜单服务拉起来；
3. 「4 直播」：复制榜单网址，粘给 OBS（浏览器来源）或直接用浏览器打开。

榜单网址可以带参数控制显示效果（多个参数用 `&` 连接），完整列表见 `docs/参数速查.md`。常用组合：

```text
?overlay=1                  OBS 用：透明背景、不显示任何控件
?rows=12&scroll=1           一屏 12 行，定时扫榜滚动
?auto=0&ctl=1&rows=0        人工查看：关自动滑动、显示控制条、显示全榜
?freeze=audience            封榜视角（观众视角）
?freeze=operator            操作员视角
?thaw=1                     解榜，显示真实成绩
?ctlhide=0                  控制条一直显示（不自动淡出）
?ctlhint=0                  不要「加载后先亮一下」的首次提示
```

翻榜有三种方式：鼠标滚轮、键盘 `PageUp / PageDown / ↑ / ↓ / Home / End`、页面右侧中部的控制条滑动条。控制条默认自动隐藏，滚轮一动就出现，停手 4 秒后淡出。

## 六、赛后滚榜

1. 「1 数据源」：确认比赛数据（`contest.json` / 题目集）没问题；
2. 「2 外观」：按需设置奖项、队伍照片、校徽；
3. 「3 滚榜」：生成比赛包并启动 Resolver。

队伍照片和校徽放进程序目录下的「滚榜图片」和「校徽」两个文件夹。命名规则（按学号最稳、默认校徽怎么放等）见程序界面里的对应说明。

## 七、端口

榜单服务默认端口是 **8791**。端口被占用时到「3 服务」页改成别的（例如 8765），程序启动前会检查占用并提示。

外榜服务默认端口是 **8099**，只监听 `127.0.0.1`，由 nginx 反代到公网。

## 八、隐私提醒（重要）

- Cookie 等同于你的登录状态，谁拿到它就能以你的身份访问 PTA。不要外发、不要截图发群、不要粘到聊天窗口里。
- 程序会在自己所在的目录里生成配置文件（`config.json`）、运行数据（`live/` 目录）和日志（`logs/` 目录）。这些是每台机器各自生成的，不进仓库。
- 仓库里已经清理掉作者机器上的设置、历史记录、日志和 Cookie，并且不含任何真实比赛数据；别人拉下来是全新的干净环境。

## 九、常见问题

见 `docs/FAQ.md`。最常见的三条：

- 点「启动」后榜单打不开：确认本机装了 Python 3.9+，再看「3 服务」页日志或 `logs/` 下的文件；
- 提示 401 / 一直取不到数据：Cookie 失效，按第四节重新复制（两个字段都要带）；
- 中文显示成方框：字体没找到，放入 `tools/fonts/` 或在「外观」页指定字体。
